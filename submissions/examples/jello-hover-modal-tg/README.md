# Jello Hover Modal for Dashboard Analytics

## Overview

A modern Dashboard Analytics interface featuring a pure CSS Jello Hover Modal with smooth elastic animations. The component is designed to provide an engaging user experience while remaining lightweight, responsive, and accessible.

## Features

- Pure HTML & CSS implementation
- CSS-only modal (no JavaScript required)
- Smooth Jello open and hover animations
- Responsive dashboard layout
- CSS Custom Properties for easy customization
- Keyboard-accessible controls
- Accessible semantic HTML structure
- Supports reduced-motion preferences

## Customization

The animation can be customized using CSS variables:

```css
--jello-duration
--jello-easing
--hover-duration
--modal-radius
```

Works in all modern browsers supporting:
